# 速导航浏览器插件

一个功能完整的网址导航浏览器插件，支持自定义分类和数据导入导出。

## 功能特点

### 导航系统
- **主类导航**：顶部或侧边栏展示主要功能分类
- **一级导航**：作为主类导航的子菜单
- **二级分类**：展示具体分类下的详细内容，支持响应式布局
- **卡片式展示**：每个网站以卡片形式展示，包含logo、名称、描述和标签

### 数据管理
- **JSON数据存储**：使用JSON格式作为数据存储标准
- **多存储类型支持**：
  - **本地存储（local）**：使用浏览器本地存储，适合轻量级数据
  - **IndexDB存储**：使用浏览器内置的IndexDB，适合大量数据
  - **MySQL存储**：支持连接外部MySQL数据库，适合跨设备数据同步
- **本地持久化**：浏览器重启后数据不丢失
- **数据导入**：支持通过文件选择器导入JSON格式数据
- **数据导出**：支持将当前数据以JSON文件格式下载到本地，同时支持SQL导出
- **数据同步**：支持不同存储类型之间的数据同步
- **默认数据**：内置常用网址数据，方便用户快速使用
- **云备份管理**：支持通过WebDAV进行数据备份和恢复
  - 手动备份数据到WebDAV服务器
  - 自动备份功能，支持每日/每周/每月备份
  - 可配置备份时间（默认凌晨0点）
  - 支持测试WebDAV连接
  - 从WebDAV恢复数据

### 图标管理
- **多API支持**：支持配置多个图标获取API，包括主API和备选API
- **默认图标类型**：支持小地球图标和文字图标两种默认图标类型
- **图标缓存**：优化的图标缓存机制，提高加载速度

### 用户体验
- **现代化UI**：符合现代浏览器插件设计规范
- **平滑动画**：导航层级之间的平滑切换动画效果
- **响应式设计**：适配不同浏览器和屏幕尺寸
- **键盘支持**：支持键盘快捷键操作
- **无障碍支持**：确保所有可交互元素可通过键盘访问

## 技术实现

### 浏览器扩展API
- 使用Chrome扩展API开发，兼容Firefox等主流浏览器
- 采用Manifest V3规范

### 模块化设计
- **数据管理模块（dataManager.js）**：负责数据的增删改查、存储管理和数据验证
- **数据库管理模块（db.js）**：封装不同存储类型的操作，提供统一的数据库接口
- **备份管理模块（backup.js）**：处理数据备份和恢复功能
- **弹出页面模块（popup.js）**：实现插件弹出页面的交互逻辑
- **选项页面模块（options.js）**：实现插件设置页面的交互逻辑

### 存储管理
- 支持多种存储类型，通过统一接口进行操作
- 存储类型可动态切换，无需修改业务代码
- 内置数据缓存机制，减少存储访问频率
- 支持数据压缩，减少存储占用空间
- 自动数据验证，确保数据完整性

### 性能优化
- 数据懒加载，按需加载数据
- 高效的DOM操作，减少重排重绘
- 优化的渲染性能，采用虚拟DOM思想
- 图标缓存机制，减少网络请求
- 内置数据压缩，提高存储效率

### 安全性
- 完善的数据验证机制，防止恶意数据注入
- 安全的文件处理，防止XSS攻击
- 敏感信息加密存储，保护用户隐私
- 跨域请求安全处理，遵循浏览器安全策略

## 安装说明

### 开发模式安装

1. 下载或克隆本项目到本地
2. 打开Chrome浏览器，进入扩展管理页面（chrome://extensions/）
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目根目录（包含manifest.json的目录）
6. 插件安装成功，可在浏览器工具栏看到插件图标

### Firefox安装

1. 下载或克隆本项目到本地
2. 打开Firefox浏览器，进入扩展管理页面（about:addons）
3. 点击齿轮图标，选择"调试附加组件"
4. 点击"临时载入附加组件"
5. 选择项目根目录下的manifest.json文件
6. 插件安装成功，可在浏览器工具栏看到插件图标

## 使用指南

### 基本使用

1. 点击浏览器工具栏中的插件图标，打开导航面板
2. 在左侧选择主类导航（如"综合导航"、"AI类导航"等）
3. 在顶部选择一级分类
4. 在内容区选择二级分类标签
5. 点击网站卡片即可打开对应网站

### 数据管理

1. 右键点击插件图标，选择"选项"，打开设置页面

2. **存储类型配置**：
   - 在"存储管理"选项卡中选择存储类型（本地存储、IndexDB或MySQL）
   - 如果选择MySQL存储，填写数据库连接信息并测试连接
   - 保存配置后，所有数据将使用新的存储类型

3. **数据同步**：
   - 在"数据管理"选项卡中选择源存储类型和目标存储类型
   - 点击"同步数据"按钮，将数据从源存储同步到目标存储

4. **数据导出**：
   - 选择导出类型（JSON或SQL）
   - 选择导出源存储
   - 点击"导出数据"按钮，将数据导出到本地文件

5. **数据导入**：
   - 点击"选择文件"按钮，选择JSON格式数据文件
   - 点击"导入"按钮，将数据导入到当前存储

6. **重置数据**：
   - 点击"重置为默认数据"按钮，恢复内置默认数据
   - 此操作会覆盖当前所有数据，请谨慎操作

## 图标管理

### 图标生成

项目提供了一个PowerShell脚本`create-icons.ps1`，用于生成不同尺寸的图标。使用方法：

1. 确保已安装PowerShell 5.1或更高版本
2. 准备好SVG格式的原始图标文件
3. 运行脚本：
   ```powershell
   .\create-icons.ps1 -SourceIcon icon.svg -OutputDir icons\
   ```

### 图标使用

插件使用Font Awesome图标库作为默认图标，同时支持自定义图标URL。
